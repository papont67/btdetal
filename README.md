# btdetal-prices

Python-библиотека для еженедельных прайсов **БТДеталь**. Принимает XLS/XLSX,
оставляет товары с положительным остатком и сохраняет «1-ю цену» в SQLite.
Поиск по «Артикулу» и «Номенклатуре» работает без повторного чтения Excel.

## Установка

Python 3.10+, SQLite 3.34+ с FTS5 и токенизатором trigram.
Обычные современные сборки CPython уже содержат подходящий SQLite.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[dev]"
```

Пакет для установки называется `btdetal-prices`, импорт — `btdetal`.
Библиотека не требует авторизации, доступа к почте или внешнего сервера БД.

## Использование

```python
from btdetal import BtdetalParser

parser = BtdetalParser("data/btdetal.sqlite3")

# Один раз при получении нового прайса.
report = parser.import_price(
    "Прайс_14.09.2026 1-я цена.xlsx",
    price_date="2026-09-14",
)

# При каждом поиске сайт обращается только к базе.
result = parser.search("198741")
batch = parser.search_many(["198741", "Втулка Braun"], max_results=10)
```

В `import_price()` также можно передать `bytes` или бинарный поток загруженного
файла. Поток читается с текущей позиции. Пользовательский файл не изменяется.
Для повторной передачи уже прочитанного потока вызовите `seek(0)`.

В новом процессе достаточно `BtdetalParser("data/btdetal.sqlite3")`: импортировать
Excel заново при запуске приложения не нужно.

## Поиск и формат ответа

Поиск находит буквальную подстроку в любой из двух колонок без учёта регистра.
Пробелы нормализуются, пунктуация и ведущие нули сохраняются. Поиск по названию
подразумевает непрерывную фразу; перестановка слов и поиск всех слов независимо
не выполняются. Код поставщика не участвует в текстовом поиске.

Формат соответствует Omnia/Ziphol: `query`, `status`, `products`, `count`,
`fetched_at`; цена — строка с двумя знаками после точки, валюта `RUB`.
Лимит по умолчанию — 3. При превышении возвращается `too_many_results`,
`count_at_least` и **пустой** `products`, без незаметного усечения выдачи.
Отсутствие совпадений — `not_found`; отсутствие базы — исключение `BtdetalError`.

`id`/`code` — строковый «Код» поставщика с сохранением форматированных нулей.
Товары без артикула остаются доступны по названию. Повторные артикулы допустимы,
повторные коды у доступных товаров считаются ошибкой файла.
`url`, `image_url`, `search_url` равны `null`, `quantity_prices=[]`:
в прайсе нет ссылок, фотографий и количественных скидок.

Товары с остатком, но без цены сохраняются с `price=null`, `status="error"`
и `price_is_current=false`. Выдача с таким товаром имеет `status="partial_error"`,
как в Omnia. Пропуск цены не превращается в ноль и не блокирует остальные товары.

Остаток и `price_is_current=true` относятся к **последнему загруженному прайсу**,
а не к наличию в реальном времени. `fetched_at` — время импорта в UTC, оно
не обновляется при поиске. `price_date` — явно переданная дата прайса; если
она неизвестна, возвращается `null`. По имени файла дата не угадывается.
Старый прайс автоматически не удаляется; сайт может показывать его возраст.

## Обновление и интеграция

Файл сначала полностью проверяется. Замена товаров, поискового индекса и
метаданных происходит одной транзакцией. При ошибке остаётся прежний прайс.
Отсутствующие в новом файле товары удаляются. Пустой прайс по умолчанию
отклоняется; намеренно очистить данные можно через `allow_empty=True`.

Читатели SQLite WAL продолжают видеть целую прежнюю версию во время записи,
а после коммита новые запросы видят новую. Каждый вызов открывает отдельное
соединение; один объект можно использовать из разных потоков.
Индекс FTS5/trigram ускоряет поиск подстрок от трёх символов; запросы из одного
или двух символов сканируют таблицу с лимитом выдачи.

Подробности интеграции с будущим сайтом: [docs/integration.md](docs/integration.md).
Контракт: [docs/api.md](docs/api.md). История: [docs/changelog.md](docs/changelog.md).

## Проверки

```powershell
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m ruff check .
.venv/Scripts/basedpyright.exe
.venv/Scripts/python.exe -m build
```

Тесты создают небольшие искусственные XLS/XLSX и проверяют оба формата,
поиск, числовые форматы идентификаторов, ошибки импорта и согласованность
чтения при обновлении. Исходный прайс и локальная база не включаются в пакет.
