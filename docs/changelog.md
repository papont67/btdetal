# История изменений

## Без проверки даты — 2026-09-17

- Убрана проверка формата `price_date`: необязательная строка хранится как передана.
- Дата не ограничивает импорт; примеры загрузки не требуют её передачи.
- Убрана рекомендация сравнивать даты прайсов на сайте.

## 0.1.0 — 2026-09-17

- Приём XLS/XLSX по пути, байтами и бинарным потоком.
- «1-я цена», положительные остатки, сохранение ведущих нулей и товаров без артикула.
- Атомарное обновление постоянной SQLite-базы с индексом FTS5/trigram.
- Поиск по артикулу и номенклатуре, одиночный/пакетный контракт Omnia/Ziphol.
- CLI, примеры интеграции сайта, тесты, Ruff и Basedpyright.
